# Personal Portfolio Website

A full-stack portfolio web application built to showcase my software development projects, technical skills and professional experience.

**Built with React, Vite, JavaScript, Node.js and Express.**

## Overview

This project is a personal portfolio website developed to provide a central place to showcase my development work and technical experience. It uses a React frontend alongside a Node.js and Express backend to dynamically retrieve and display project information through REST API endpoints.

## Tech Stack

**Frontend**
- React 19
- JavaScript (ES6+)
- Vite
- React Router
- Sass (SCSS)
- React Icons

**Backend**
- Node.js
- Express.js
- REST APIs
- JSON
- CORS

**Deployment**
- Vercel

## Key Features

- **Dynamic Project Data:** Retrieves portfolio project information from a JSON data source through an Express API.
- **REST API Integration:** Connects the React frontend to the Node.js backend using HTTP requests and JSON responses.
- **Component-Based Architecture:** Uses reusable React components to organise and maintain frontend functionality.
- **Client-Side Routing:** Implements React Router for navigation between portfolio sections.
- **Custom Styling:** Uses Sass to organise styling and maintain a consistent interface.
- **Performance Analytics:** Integrates Vercel Analytics.
